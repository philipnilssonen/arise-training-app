# ARISE — Hunter Training System

Gamifierad träningsapp (Solo Leveling-inspirerad). Hela appen är en enda fil, `index.html`, hostad via GitHub Pages.

**Live URL:** https://philipnilssonen.github.io/arise-training-app/

## Pusha nya ändringar live

Appen live-uppdateras genom att pusha till `main`. Kör dessa kommandon från projektmappen efter att du ändrat `index.html`:

```bash
git add index.html
git commit -m "Beskrivning av ändringen"
git push
```

GitHub Pages bygger om automatiskt (tar oftast under en minut).
